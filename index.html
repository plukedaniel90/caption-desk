From subtitle file to useful clip

This is a working subtitle editor. You can use it alone, immediately.

  1. Try the built-in example, or import an SRT/VTT subtitle file you already have.
  2. Select a caption, edit its words or times, then press Save caption.
  3. Open the matching video from your device to check timing.
  4. Export the full subtitles, or set a clip start/end and export its rebased SRT.
  5. Save a JSON backup before closing or switching devices.

It does not transcribe, translate, colour-grade, crop or render video. Plain subtitle text and timing are supported; source styling is omitted with a notice.
